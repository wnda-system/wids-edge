WiFi Packet Capture

Capture live WiFi traffic and export it as a CSV file.
Open a terminal on this computer and run, in order:
  1. iw dev — lists your WiFi adapters and interface names.
  2. sudo ip link set <interface-name> down
  3. sudo iw dev <interface-name> set type monitor
  4. sudo ip link set <interface-name> up
  5. Run iw dev again to confirm — the interface should now show type monitor. That exact name goes in the box above.
Note: this locks the adapter to one WiFi channel, so it will only see traffic on that channel.
Pick at least one — whichever limit is hit first stops the capture. You can also stop manually at any time.
